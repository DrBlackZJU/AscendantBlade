# 擢升之刃 · AscendantBlade

一款以火柴人格斗为核心的网页动作生存游戏。挥刀迎战不断涌来的敌人，通过连斩、蓄力、完美格挡与处决积累优势，再以「擢升」组合出属于自己的战斗流派。

**在线游玩：[https://drblackzju.github.io/AscendantBlade](https://drblackzju.github.io/AscendantBlade)**

推荐使用带键盘的电脑浏览器游玩。进入页面后，点击「迎战敌潮」或按 `Enter` 开始。

## 游戏特色

- **近身攻防**：短按连斩、移动蓄力、突刺与空中下劈，配合无敌冲刺应对围攻。
- **架势与处决**：把握时机完美格挡，削减敌人架势；击破架势后可发动处决，完美格挡还可弹回投射物。
- **擢升构筑**：击杀敌人获取经验，升级后获得擢升机会；不同擢升之间可形成连锁效果，并解锁双重擢升。
- **递进敌潮**：随着战斗推进，迎战人类、变异、怪物与深渊等不同阶段的敌人和首领。
- **视听体验**：骨骼动画、战斗特效，以及随战况切换的背景音乐。
- **中英双语**：可在页面右上角切换中文与英文，并分别控制音效、音乐和音乐音量。

## 游戏模式

- **迎战敌潮**：在持续推进的敌潮中生存、升级，迎接首领与最终决战。
- **BOSS RUSH**：连续挑战首领，每击败一名首领可获得 3 次擢升机会。

## 操作说明

| 按键 | 功能 |
| --- | --- |
| `W` / `A` / `S` / `D` | 移动 |
| `Space` | 跳跃，可二段跳 |
| `Shift` | 无敌冲刺，有冷却时间 |
| 短按 `J` | 连斩 |
| 长按 `J` | 移动蓄力重击 |
| `Shift` + `J` | 突刺 |
| 空中 `S` + `J` | 下劈，命中敌人可刷新冲刺与二段跳 |
| `K` | 格挡，恰当时机使用可完美格挡 |
| `Q` | 处决架势被击破的敌人 |
| `R` | 战意爆发，消耗 80 战意 |
| `E` | 有待用擢升机会时，暂停战斗并打开擢升选择 |
| `1`–`5` | 在擢升界面选择对应选项，以实际显示为准 |
| `Tab` | 查看修习录中的已有擢升 |
| `H` | 打开或关闭战斗手册 |
| `Esc` | 暂停或继续战斗；在帮助、修习录界面可返回 |
| `M` | 切换背景音乐 |
| `N` | 切换特效音效 |

## 上手建议

1. 先熟悉短按连斩与冲刺，给自己保留脱离包围的空间。
2. 观察敌人的攻击节奏，练习完美格挡，再用处决打破僵局。
3. 留意待用的擢升机会，按 `E` 选择强化，按 `Tab` 回顾已有组合。
4. 被围攻时可使用战意爆发争取喘息时间；详细机制可随时按 `H` 查看。

## 本地运行

项目使用原生 HTML、JavaScript 和 Canvas，无需安装前端依赖或执行构建。

下载或克隆仓库后，在项目根目录启动静态文件服务器。例如，已安装 Python 时可运行：

```bash
python -m http.server 8000
```

然后在浏览器中打开 [http://localhost:8000](http://localhost:8000)。请保留 `music/` 目录，以便正常加载背景音乐。

| 文件 / 目录 | 用途 |

| `index.html` | 页面入口与游戏界面 |
| `game.js` | 游戏主流程、敌潮、界面与画面渲染 |
| `combat.js` | 战斗模拟与角色攻防逻辑 |
| `enemy.js` | 敌人目录与配置 |
| `boss.js` | 首领相关逻辑 |
| `ascensions.js` | 擢升、双重擢升与效果逻辑 |
| `motion.js` | 骨骼动画 |
| `combat_fx.js` | 战斗特效 |
| `music.js`、`music/` | 背景音乐控制与音频资源 |
| `i18n.js`、`i18n-en.js` | 中英文切换与翻译 |
