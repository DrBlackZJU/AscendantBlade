# 2026-09-27 定向修订

按最新要求停止全体敌人扫描，本轮只完成指定美术、动作、战斗修复及双重擢升。

## 美术与动作

- 移除本次重绘模型的黑色外描边，保留必要的内部结构与五官。
- 食尸鬼平时闭嘴、双爪向前；吞噬者采用更低、更长的爬行食尸鬼姿态，仅进食动作张嘴。
- 缝合骑兽延长为尸堆，六条步行腿和三条额外悬空手臂。
- 寻血猎犬使用黄白、淡红；裂地兽使用黄棕；幽灵使用淡蓝灵体；深渊触手加入弯曲软体轮廓及吸盘。
- 祭司采用法师式帽袍与法杖。腐坏祭司、腐化督军使用腐坏绿黄配色。依照后续反馈，已撤销第2类统一配色，其他敌人恢复各自原有配色。
- 亡灵法师召唤的骷髅采用分段骨骼、明确的前摇、接触及收招；超出屏幕边缘后淡出死亡，不再瞬移追随玩家。
- 雕像完成当前攻击及后摇后，进行0.85秒石化动作，再开始完整静止时长。石化或静止状态死亡时碎块倒塌，地下吞噬等特殊死亡优先。
- 冥想使用绿金流光、环绕光束与上升光点；杀意复用终极形态的霸气轮廓并改色。

## 尸体与处决

定位到处决后摇持续插值追随死亡目标坐标，尸体飞出时因此拖动玩家。现于处决命中时固定玩家收招坐标；目标提前死亡时同样停止追随。

处决触发保龄球时，尸体向远离玩家的一侧飞出。回归检查覆盖两种朝向及普通飞行尸体穿过玩家的情况。
