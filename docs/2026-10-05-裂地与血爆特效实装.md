# 裂地与血爆特效实装

按五组美术试映接入生产绘制，后续范围修订：血潮与尸爆术保留原有特效。

- **余震（d78）**：满蓄岩石突刺的第二段保留二重斩现有金橙地裂喷发，沿突刺方向再延长一道 420 长度的裂缝。新裂缝使用同款喷发造型，逐段推进；不再额外画岩石排。普通二重斩与非满蓄余震仍使用基础绘制。延长的裂缝增加视野裁切余量，落点在屏外时也可看到进入画面的裂缝末端。
- **双重血爆**：盛大谢幕（d179 / alphaBloodFeast）、浴血盛宴（d30 / bloodExecutionerBurst）使用弯曲液膜、喷流、弹道血滴和不规则地面血迹；盛大谢幕连杀数影响视觉密度。浴血盛宴保留普通 / 首领原有范围。
- **岩石突刺**：按后续反馈缩小为冲刺过程中脚边震起的小岩石：五处稀疏岩块、本体高度约 10–18，少量低空碎屑和轻尘，约 0.82 秒收尾。取消整道地裂与高密岩脊；保留小岩块的明暗断面与石纹。事件增加面向与实际突刺长度，绘制随原有攻击范围变化。
- **普通 stone 震波**：用不规则地裂、翻起的薄地块、贴地尘浪和低空碎屑替换实心石色地面盘。震踏与其他 stone 事件共用此配方。
- **大震踏**：quake 的 big 标志改走独立绘制，包含中心塌陷坑、厚岩层翻起、粗地裂和两拍重尘浪。使用事件原有半径（标准大震踏为 320）；移除旧震踏岩石叠层。

伤害、架势伤害、范围判定、冷却和随机数结算保持原逻辑。岩石突刺命中后的气压冲击波保持上一轮实装。血潮 / 尸爆术的通用 blood 分支和 0.7 秒生命周期保持原样。

## 文件

- `combat_earth_blood_fx.js`：五组共享绘制。
- `game.js`：特效路由、生命周期、裁切和旧效果移除。
- `ascensions.js`：二重斩事件补充定向延伸长度与面向。
- `combat.js`：突刺事件补充实际攻击长度与面向。
- `index.html`：加载绘制脚本，更新关联脚本版本。
- `tests/earth-blood-preview.html`：美术对照与慢放，使用生产配方。
- `tests/earth-blood-runtime.html`：真实游戏事件处理与绘制验收；只用于测试。

## 验证

通过 JavaScript 语法检查、`earth-blood-smoke.cjs`、`heavy-impact-smoke.cjs`、`quake-stomp-smoke.cjs` 和 `overkill-bladeshock-smoke.cjs`。

新增检查覆盖：两种突刺方向、满蓄 / 非满蓄余震、第二段延迟、定向范围、真实突刺与两项双重血爆触发、伤害 / 架势 / RNG 对照、路由生命周期与清理、屏外裂缝、原有血潮 / 尸爆分支，以及 21400 帧有限数值与 Canvas 状态平衡检查。

以上验证针对首次实装版本。后续仅缩小、疏化岩石突刺的绘制，按用户要求未重复测试；其余美术保持已验收版本。
