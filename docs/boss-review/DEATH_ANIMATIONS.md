# BOSS 死亡短动画 · 2026-09-30

本轮按用户逐项要求调整 33 位流程 BOSS 与两位最终魔将的死亡表现，并增加利爪兽钻地时的地表背刺。全部死亡表现沿用约 0.8 秒的正常尸体虚化时间；身体、阴影、掉落武器、碎片、火焰和散开粒子在同一透明度作用域内绘制，时间结束后完全不再绘制。

10 月 1 日追加反馈已处理：飞蛾死亡散群改为 38 个小椭圆，取消精细小蛾模型，保持散开和共同虚化节奏；逐帧验证再次通过。

## 实现入口

- `boss_models.js`：共享死亡时间与透明度、倒下/侧倒、坍塌分层、焚烧腐化、散蛾、吞噬、钟体裂缝、地表背刺。
- `human_boss_art.js` / `mutant_boss_art.js`：用实际武器造型做掉落，断手与晶爪残躯、熄灭水晶、回胸嵌剑。
- `aberrant_boss_art.js` / `abyss_boss_art.js`：钟舌敲击、触手断段、落爪、悬石掉落。
- `boss_encounters.js`：死亡时冻结 BOSS 模型时钟、停止原攻击；分蛾代理同步处理。移除旧的模拟驱动魔将死亡光圈，改用尸体时间驱动的爆炸。
- `boss_art.js` / `game.js`：最终魔将倒下和四次紫色爆炸。最终战结束等待仍推进 `deathT`，所以战斗模拟暂停后爆炸也不会冻结。

战斗数值和既有自爆、冠军一次复生、浮囊三囊生成逻辑不变。BOSS RUSH 的奖励等待不再让死亡附属视觉残留，奖励时机不变。
