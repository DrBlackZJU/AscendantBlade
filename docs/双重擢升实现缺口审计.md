# 双重擢升实现缺口审计（2026-09-30 补齐）

本轮依据修复前审计和用户最新规则完成代码修改。下方历史审计仅用于追溯，不代表当前缺口。

## 当前结论

- 当前共有 311 个双重擢升；原先 42 个无专属运行入口的组合均已接入。
- 原先空操作的「借势藏锋」已接入藏锋额外伤害与斩杀阈值的实际蓄力倍率；不再依赖无人读取的 `borrowEdge`。
- 「幽藤索命」已改为每秒 18 生命／24 架势；「解构首刀」已补齐暴击相关易伤和击杀经验倍率。
- 「影遁追魂」提升到 85 生命／50 架势；同时持有「幽影还击」时保留两者触发机会，统一只结算一次较高伤害。
- 巨人杀手、野兽杀手、无情等未限定来源的目标增伤进入共同生命／架势伤害结算，覆盖持续伤害、召唤物、反射和处决；普通暴击判定仍限于 J 攻击，特定元素／召唤双重按原规则另行处理。
- 游刃有余各级受击仅失去 2 层；移除停止移动或受击后的 0.7 秒收益保留。冥想双重的持续积层仍独立生效。
- 卡面、`dual_catalog.json` 和「擢升与双重擢升当前游戏文本.md」已同步。「幸运炼金」显示名称统一为「幸运炼炉」。

# 修复前审计记录

> 本文件用于开发核对，不是玩家卡面。审计基于当前项目 `ascensions.js` / `survival.js` 的实际触发钩子、父卡组合判定与状态读写。对未检出实际实现的双重，本轮没有凭旧设计文案虚构数值。

## 结论

- 当前双重擢升共 311 个。
- 本轮已对有明确运行时实现、且原文案缺少关键数值的一批双重进行玩家文本精确化。
- 修复焚刃千击、死门常开、蚀骨剧毒、痛觉燃料、三阳回照后，仍有 **42 个没有专属运行入口** 的双重；此前 4 个链路未闭合项已补齐。
- 已扫描项目内全部 JavaScript：这 42 个组合既没有正向或反向的 `pair/hasDual/dualForParents` 判定，也没有按双重 ID 处理的分支。当前获取它们后，不会产生卡面所述的专属效果。
- 另发现 **1 个有分支但实际为空操作的双重**：`借势藏锋` 只写入 `borrowEdge`，后续没有任何读取或消费；开启双重前后的攻击结算相同。
- 另有 **2 个部分实现异常**：`幽藤索命` 的伤害强化方向错误；`解构首刀` 只有通用伤害加成生效，卡面所述暴击易伤与额外经验倍率均未接入结算。

## 文本处理原则

1. 已确认实现的效果：玩家文本优先写出伤害、架势、持续时间、周期、范围、概率、倍率、阈值、冷却等实际常数。
2. 百分比概率变化尽量写“百分点”；倍率变化写 `×1.xx` 或明确“提高 xx%”。
3. 动态公式无法压成单值时，直接写公式或上下限，不用“小幅/大幅/进一步”等模糊等级词。
4. 未检出实现或只接一半的效果：不根据旧 `detail` 猜测数值；保留为开发审计项，后续应先补实现，再补精确卡面。
