## 独立游戏借梗：最值得用的部分

借梗优先看操作或收益结构是否相近；只有元素颜色相同、职业相同或听起来酷，通常不足以换名。下面列出本轮比较有依据的独立游戏关联。英文名用来定位原对象，中文候选不统一声称是官方译名。此表属于命名关联判断，不是逐版本技能考据；差异也一并列明。

| 本作条目 / 候选 | 原作与原对象 | 关联强度 | 能借到什么 | 本作的主要差异 |
| --- | --- | --- | --- | --- |
| `sharpShadow` 锋利之影 | 《空洞骑士》Sharp Shadow | 强 | 冲刺穿过敌人造成伤害、强化冲刺距离 | 本作分等级并加流血与恢复收益 |
| `prideMark` 骄傲印记 | 《空洞骑士》Mark of Pride | 强 | 延长骨钉 / 近战攻击距离 | 本作另加攻速与剑尖命中奖励 |
| `iceBarrier` 冰甲 | 《Dead Cells》Ice Armor | 强 | 一次护甲保护，触发后冻结周围敌人 | 本作主要减伤而非完整挡掉一次攻击，附持续冻伤 |
| `giantKiller` 巨人杀手 | 《Dead Cells》Giantkiller | 强 | 擅长对付精英和首领 | 本作还依目标高生命区间与格挡提供收益 |
| `d116` 混沌 | 《Slay the Spire》Chaos | 强到中 | 随机生成充能球 | 本作由子弹时间触发、可临时溢出、结束统一激发，不是打出一张卡 |
| `d223` 冰川 | 《Slay the Spire》Glacier | 强到中 | 冰霜球与防御组合 | 本作为冰球补足护盾空窗；原作直接给格挡并生成冰球 |
| `d278` 电动力学 | 《Slay the Spire》Electrodynamics | 强到中 | 雷球由单体收益变成群体收益 | 本作激发雷球引爆全场雷印，仍要求目标带印 |
| `d222` 嗝屁猫项圈 | 《以撒的结合》Guppy's Collar | 强 | 死亡时独立概率复活 | 本作20%且不消耗常规复活机会；原道具基础概率与回复方式不同 |
| `d297` 黑暗艺术 | 《以撒的结合》Dark Arts | 中 | 穿过目标后延迟统一结算攻击 | 本作先格挡武装冲刺，以空间裂隙尾爆；原作有自己的无敌、标记与攻击规则 |
| `rage` 幼虫之歌 | 《空洞骑士》Grubsong | 中 | 受伤获得技能资源 | 本作获得战意，并额外延长无敌时间、触发爆发，不是灵魂资源 |
| `d151` 荒芜俯冲 | 《空洞骑士》Desolate Dive | 中 | 向下打击与落地范围冲击 | 本作是连续骨钉下劈，累计次数追加巨震，不是独立施法按钮 |
| `d42` 噬魂者 | 《Vampire Survivors》Soul Eater | 中 | 范围攻击敌人并取得治疗 | 本作需蓄力汲魂，并加强饮血重击，不是常驻升级武器光环 |
| `thorns` 荆棘护甲 | 《空洞骑士》Thorns of Agony | 中 | 挨打后用荆棘回击 | 本作是单目标反伤、减伤与流血，满级完美格挡也触发 |

最适合直接保留的独立游戏梗是锋利之影、骄傲印记、巨人杀手、嗝屁猫项圈、冰川、电动力学。新增候选中，冰甲、混沌、黑暗艺术可以优先考虑；幼虫之歌更偏明确致敬，是否适合取决于你是否愿意让本作出现这个较温柔的生物名。

### 已有引用中，适合保留与需要分清的部分

| 名称 | 引用 / 意象 | 命名判断 |
| --- | --- | --- |
| 索伦魔眼 | 《魔戒》的巨眼凝视 | 单眼融合实体与压迫感非常贴，保留 |
| 原子吐息 | 《Godzilla》的蓝色吐息 | 蓝色强化龙息视觉直接支持这个梗，保留 |
| 星之彩 | 洛夫克拉夫特《The Colour Out of Space》 | 陨石、污染、永久侵蚀构成完整关联，保留 |
| 石像鬼板甲 | 《英雄联盟》Gargoyle Stoneplate | 多敌近身时更坚固的核心联想成立，保留；版本细节不同 |
| 阿尔法突袭 | 《英雄联盟》Alpha Strike | 高速串联攻击可联想，但本作是串联可处决敌人 |
| 幕刃 | 《英雄联盟》德拉克萨幕刃历史版本 | 暗杀与隐匿主题适合；不能视为全部版本都同效果 |
| 狂徒之心 | 《英雄联盟》Warmog's Armor 的生命再生意象 | 高生命带来更强恢复可成立；条件、比例不同 |
| 狂暴之刃 | 《英雄联盟》Guinsoo's Rageblade 的叠层攻速 | 连续命中攻速叠加很近；不借其全部命中特效规则 |
| 置闰仪式 | 《Cultist Simulator》的太阳与 Intercalate 仪式意象 | 太阳形态延长的主题适合，属于意象梗而非同技能 |
| 创世纪 | 《以撒的结合》Genesis | 原道具重建持有道具，本作重掷时调整双重权重，关联偏松；建议把它作为次选 |
| 永恒六面骰 | 《以撒的结合》Eternal D6 | 原道具重掷且可能移除底座道具，本作升级时给敌人厄运，只是骰子意象；可保留趣味，勿称同机制 |
| 碎片整理 | 《Slay the Spire》Defragment | 原卡增集中，本作让球加入协同数量统计，建议改为编队成型 |
| 疯狂修理 | 《Slay the Spire》Self Repair 的治疗主题 | 原卡战后治疗，本作精灵持续无阈值治疗，属于改写梗；疯修的反差本身仍好用 |
| 超频 | 《Slay the Spire》Overclock / 通用技术词 | 原卡抽牌并加入灼伤，本作额外充能球；建议理解为通用技术词，或选机制更近的混沌 |
| 死门 | 《Darkest Dungeon》Death's Door | 都有濒死仍战斗的语气，本作为复活后增益窗口 |
| 拒绝死亡 | 《Undertale》的决心与死亡叙事 | 适合保留叙事语气，本作具体是低生命再生 |
| 链锯剑 | 《Warhammer 40,000》Chainsword 等链锯武器形象 | 器物本身成立，不需要要求数值等价 |
| 猎魔人 | 《The Witcher》的委托猎怪职业 | 职业与独立非人形赏金吻合，但并非所有非人形都是魔物 |

“华冠曲、棘发曲、守夜人辉光、粉碎之手”等名字本轮可以基于气质或实体保留，但没有在缺乏可靠出处时补认成某款游戏的官方技能。它们是否还承担你已有的私人梗，可以在定稿时按你的原意保留。

## 应当成组定稿的几个系列

| 系列 | 建议组织方式 | 推荐组合示例 |
| --- | --- | --- |
| 攻守剑灵 | 成对短名；不要一边分类名、一边神话名 | 攻剑＋守剑 → 双剑合璧；同频护卫；鬼手代刑属于另一召唤分支 |
| 暗伤 | 用记账与清算保持关联；配少量身体伤势词 | 暗伤 → 一次清算、秋后算账、亡者记账、欠命难还、生来带伤 |
| 格挡反击 | 区分自动格挡、迎击、反伤和借力，不全写返刃 | 震刀、借力、返刃 → 雷电奉还、附赠三剑、三刀奉还、敲响反击 |
| 风势 | 区分移动积风、攻击用风、静止起风 | 御风 → 风助火势、顺风冲撞、静中生风、追风二式、斩出风来 |
| 空间斩 | 用触发动作与裂口轨迹区分六种组合 | 一斩多隙、裂隙吞噬、剑气留隙、处刑裂线、挡出裂口、借刀开路 |
| 环刃 | 用刀轮与具体路径为主，避免每项都叫回锋或刃界 | 贴身刀轮、长刃刀轮、一路转刀、下劈刀轮、引力绞盘、闪过也伤 |
| 补给 | 可以继续使用日常物件与加餐笑点 | 战场支援、便携烹饪锅、连杀加餐、随身书房 |

以上只是推荐体系。选其中一个次选并不要求全家族同时改；最需要成对的是攻剑与守剑，以及贴身刀轮与长刃刀轮。

## 定稿时还需要注意的文本接口

1. 格挡与概率闪避、主动冲刺是三类触发。诸如闪身、闪避与冲刺的候选不能只看字相近就交换，否则玩家会误判需要主动操作还是概率触发。
2. 灰血既有“获得灰血”和“将灰血转回生命”两种方向。生息归灰一类名字容易把恢复方向说反，本轮相应改为伤愈不停。正式润色效果时也应继续区分二者。
3. 爆发后的形态收益、星辉无敌与周期复活是三个系统。优先用化身、护佑、复生等词提示，不把短时保护统称永恒或不灭。
4. 普通卡副标题仍有“耀世焚城、一道绝影、一刺穿山、四式出锋”等偏高调或套格式的文字。正式采用更克制的主名后，副标题是下一轮值得扫描的对象；本轮保留它们作为原始对照，避免名字候选被副标题旧语气拖回去。
5. 较长的幽默次选如“动不了也躲不了”“吃一堑，敌长一智”需要在实际卡面检查换行。推荐首选一般更短；这些长名没有被假定为可以直接无条件替换。
