# 烈焰重剑扩散美术调整

烈焰重剑 LV3 的 `ignite(spread:true)` 与烈焰重剑 + 二重斩的 `emberSpreadBurst` 继续共用 `AshFireFamiliesFX.flameSpread`，改为一次迅猛的火焰爆裂与扩散。

- 起爆：短促的碎裂火芯与火舌，约 0.13 秒退出。
- 扩散：一道不规则火焰圈快速向外散开，约 0.11 秒到达外缘，约 0.31 秒熄灭；替换之前的五至七层持续火圈。
- 粒子：116 / 88 颗火星在同一短促爆发内离开爆心，包含贴地外射、向上飞溅与落下的轨迹；约 0.66 秒内消散。
- 仍按原有范围和密度绘制，保留烈焰重剑 LV3 的 145 范围及联动余火爆裂的 100 范围。游戏特效队列生命周期仍为 0.85 秒，技能伤害、点燃、扩散判定与触发频率均未更改。

修改生产 `combat_fx.js`、入口资源版本及现有火焰试映页的说明。直接接入游戏，本轮未额外运行测试。
