# 暗伤实装与赏金特效试映

## 暗伤：已实装

- 采用已确认的 1.8 倍方案：体内暗紫裂脉、暗红撕裂、短促碎屑迸散、残烟消退，全程 0.58 秒。
- 移除 `woundBurst` 的通用血色地面爆炸，以及额外的旧脚底扩圈与随机散点。
- 由目标轮廓裁切裂痕；目标被击飞或移动时，特效跟随目标位置与高度。
- 普通暗伤、半数引爆和封印释放均携带目标 ID，使用同一套专属绘制。
- 伤害数值、触发条件和累计逻辑未变。暗伤量仅决定视觉强度，在测试页的少量至大量区间内限幅。
- 原独立预览改为调用正式共享绘制器，保持后续预览与实装一致。

验证：39 种普通、精英及首领模型；移动与击飞跟随、半数引爆、屏外裁剪、特效数量上限、过期释放及重开清理通过。既有首领绘制与异常报告回归检查通过。

## 赏金：居中版已实装

- 光柱对应击杀悬赏目标后的 `bountyClaim`，本次测试设计针对奖励兑现。
- 新提案“猎印核销”：铜金猎印锁合、斜向斩痕核销、碎金迸出、收拢为奖励亮点，全程 0.78 秒。
- 测试页左右分别显示现行金色光柱与新提案；提供五种敌人、速度、逐帧、奖励强度、朝向、离地和明暗背景。
- 模型的淡出仅用于模拟击杀。碎金的收拢终点改为目标中心正上方，避免固定左移；仍为测试展示位置，尚未绑定游戏中的玩家。
- 正式 `bountyClaim` 已由圣光柱改为居中的猎印核销动画，移除原有通用金色散点；标记出现与头顶常驻标记保持原样。
- 普通悬赏、首领、兽类悬赏、幸运额外赏金、弱者印记均提供尺寸、朝向、目标 ID 和离地高度，使用同一绘制器。
- 同一击杀的多项赏金兑现合并视觉效果；每项经验、回血和灰血奖励仍按原逻辑结算。
- 测试页调用正式共享绘制器，展示与实装使用同一版居中收拢终点。
- 普通、首领、兽类、重叠、幸运、弱者六种兑现路径检查通过；重叠与幸运分别保留 40 经验、仅绘制一次动画。两种朝向的收拢亮点居中，屏外裁剪、数量上限、过期释放、重开清理及圣击光柱检查通过。
- 既有赏金收益回归与暗伤 39 种模型检查通过。正式游戏画面保存在 `.art-review/bounty-claim-integrated.png`。
