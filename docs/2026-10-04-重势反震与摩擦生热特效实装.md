# 重势反震与摩擦生热特效实装

- 重势反震采用试映中的压缩闪光、地面冲击前缘、地裂、碎石和尘浪，增加短促向外飞迸的土金粒子。单次视觉持续 1.55 秒，沿用事件的等级和范围；首领格挡、首领处决和原有组合触发均走同一配方。
- 摩擦生热仅替换 `heatBurst`：亮白爆点、向外扩散的火焰圈和飞散火星，视觉持续 0.9 秒。移除该事件原来的通用 `fire` 配方及额外圆环、粒子，避免新旧爆发叠加。原有震动与文字反馈保留，修正无 z 字段时文字坐标非数值的问题。
- 热度叠层、目标热度指示与原有 `fireTrail` / `heatGround` 地面绘制保持原样。震刀仍沿用 `posturePulse` 的 `stone` 配方。未修改 `ascensions.js`、`combat.js` 的触发和结算。
- 独立试映页的重势反震与摩擦生热爆发改为调用游戏共用的 `AshCombatFX` 配方；无需维护第二套实装视觉。

验证：三个 JavaScript 文件语法检查通过；`tests/recoil-heat-fx-20261004.cjs` 检查各等级、生命周期、镜头偏移、有限绘制坐标、Canvas 状态配对，以及实际游戏特效容器的事件路由、过期清理、屏外裁剪和 90 项数量上限。断言保留热度事件指示及震刀路由，移除两种事件的重复圆环和粒子。未完成浏览器视觉复核。
