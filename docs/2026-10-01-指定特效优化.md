# 指定特效优化与验证

按用户指定范围实施，并纳入手动测试后的微调。

| 效果 | 最终修改 |
| --- | --- |
| 共振 | 格挡弧、普通/完美格挡粒子与圈随层数渐黄；记录触发瞬间的层数，满层消耗时仍显示黄色。 |
| 游刃有余 | 脚下青蓝粒子拖尾；实测反馈后粒子约放大 1.5 倍，寿命增至 0.52–0.72 秒，发射更密，最多 96 粒。 |
| 行刑 | 周身少量紫红粒子，随 buff 层数增加，到期停止。 |
| 迅捷连锋 | 攻击时绘制少量淡银灰剑影；待机与层数到期不显示。 |
| 裂胄岩钉 | 优化已有三枚胸口石钉和爆裂；标记随后再放大 1.1 倍，爆裂保持该次微调前的版本。 |
| A07 冷却条 | 从实际 timer 和每次冷却启动时记录的总时长读取；包括初始等待、减冷却、双重和提前减剩余。 |
| 死门常开 | 独立深红气焰细纹，buff 期间在高生命时也显示。 |
| 火焰触摸 | 独立身体附着火舌与火星，跟随目标；接触触发不再绘制通用地面震波。实测反馈后放大 1.1 倍，暖色/冰焰颜色略提亮。 |
| D311 强化魂刃 | 加强刃体、紫色尾迹、边锋与火花，添加强化命中破裂；普通魂刃保留原有识别。 |
| 藏锋（后续授权） | 背后曲线拖尾改为银灰粒子，随蓄积增强，最多 18 粒；剑身效果保留。 |
| 第三批性能 A19–A22 | 雷电抖动模板、风带/书页路径和火苗色板有界缓存；每渲染帧复用目标索引；离屏裁剪保留跨屏光束；常见次级反馈按帧限量，强化/主命中不共用弱反馈额度。 |

性能处理中撤回了光晕/火苗贴图缓存，以及重复的内层裁剪检查；测量显示它们可能增加像素绘制或矩阵读取开销。当前保留直接渐变绘制。缓存上限为雷电模板 96、风带路径 1024、书页路径 16、火苗色板 16。

验证包括八种实际冷却触发路径在各等级与减冷却等级下的检查、特效状态/到期/数量上限/跨屏裁剪专项检查，以及相关战斗回归。2400 步前后数值模拟中，生命、架势、随机序列、冷却、双重状态和 661 条战斗事件一致。藏锋的叠层、消耗、追踪与返刃回归通过。用户最后一轮反馈后仅执行代码与专项回归检查，未再自行查看画面。

此前浏览器做过两个版本各 90 帧组合绘制检查，没有脚本或非有限 Canvas 参数错误。雷、风、火也分别做过 Canvas 对照测量，数据见 `.art-review/fx-tuning/browser-report.json` 和 `benchmark.json`。后端与测量方式之间存在差异：雷电有明确下降，风/火的完整绘制耗时有波动，因此不把减少路径构造等同于整局 FPS 提升，也不承诺统一提升比例。这些记录早于最后一轮大小/拖尾微调。

最初扫描对岩钉缺失的误判已在原扫描报告中更正。其他未授权的扫描项没有按本任务实施。
