# 狂牛撞击与永久恐惧 · 实装

用户确认独立试映方案，并要求移除狂牛命中目标时重复使用的震地冲击特效。

- 狂牛撞击改为独立 `bull` 特效：接触闪光、定向压缩冲击弧、前向碎屑、贴地尘浪；LV3 有追加震爆，最多持续 0.85 秒。
- 移除 `bullImpact → stone` 映射，不再生成通用震地裂纹、填充椭圆、旋转环带和石头散点；同时移除旧狂牛圆环和 18 颗散点。
- 基础撞击与滑步刺击组合撞击均携带玩家朝向和目标离地高度；新特效按接触点偏移绘制。伤害、架势、蓄势和击飞结算不变。
- 永久恐惧保留普通刺冠和淡白柔光，增加 12 颗黑色漂浮粒子和更强颤动。所有永久恐惧来源使用该标记；幻象来源仍保留紫色幻象粒子，普通临时幻象恐惧继续使用原来的紫色效果。
- 更新正式入口的相关脚本版本号，独立测试页改标记为已实装对照。

验证：正式游戏事件与渲染检查覆盖 LV2 / LV3、左右朝向、基础及组合撞击、伤害和架势保持、旧通用特效移除、过期清理、视野剔除、数量上限、重开清理，以及普通 / 永久 / 幻象恐惧和离地位置。32 个实装特效画面与确认的测试版逐像素一致。

验证脚本：`.art-review/check-bull-fear-integration.cjs`。实际游戏截图：`.art-review/bull-fear-integrated.png`。
